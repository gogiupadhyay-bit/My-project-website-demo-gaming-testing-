# Game Testing Lab 🎮

A small browser-based game testing / QA demonstration project.

## How to run
Open `index.html` in Chrome, Edge, Firefox, or any modern browser.

## What it demonstrates
- Game test mode
- Score tracking
- Miss tracking
- Accuracy calculation
- 30-second test session
- PASS/FAIL result
- Responsive UI

## GitHub Pages
Upload `index.html` to a GitHub repository and enable:
Settings → Pages → Deploy from branch → main → /root
